## Execution after the runtime-ready signal

ROOT supplies an actual `service-receipt.json` with exact final application SHA,
web tree, build ID, PIDs and corpus/isolation references. No credential or DSN is
stored in it; the existing frontend proxy supplies its own root-owned local auth.
`locatorContractReviewedAtSourceCommit` must equal the tested source commit.
The app/source trees must be clean and the actual tracked web/build/listeners
must match before browser launch. Root-owned services and all fixture setup stay
outside this harness.

From `/private/tmp/arxiv-agent-eng-workspace-mode-build`:

```sh
# Safe now: no browser/API/write execution.
env NODE_PATH=$PWD/web/node_modules node planning/14-explore-and-research-modes/evidence/d1-d4-browser/suite.cjs --prepare

# ONLY after ROOT sends the final runtime-ready/source/locator signal.
env NODE_PATH=$PWD/web/node_modules node planning/14-explore-and-research-modes/evidence/d1-d4-browser/suite.cjs --execute --receipt planning/14-explore-and-research-modes/evidence/d1-d4-browser/service-receipt.json
```

The runtime is serial per browser context so revisions cannot race accidentally.
A failed case preserves its screenshot/clip and skips dependent writes in that
context. Other fresh contexts remain independent. Held failure plans release on
failure, preventing abandoned requests or leaked interception into a later case.
The run ends `awaiting_root_restart_checkpoint`, not a pass, until ROOT restarts
the dedicated stack and supplies its restart/PID receipt. Then:

```sh
env NODE_PATH=$PWD/web/node_modules node planning/14-explore-and-research-modes/evidence/d1-d4-browser/resume.cjs --receipt planning/14-explore-and-research-modes/evidence/d1-d4-browser/service-receipt.json --checkpoint /absolute/run/restart-checkpoint.json
```

Before a final release, inspect the actual WebMs, decoded frames, screenshots,
all reports and state-preservation receipts; bind every observation to the actual
source/build and hash the final artifact scope without self-cycles. A decoder
report initially says pending visual review. Browser-emulated keyboard focus/
reduced viewport and dispatched IME/modifier event shapes are not physical OS
keyboard/IME qualification. Source/controller labels may still change before
freeze; adjust only semantic bindings from the frontend owner's confirmed
contract, preserve all failures, and never relax the acceptance assertions.
