# Direction and acceptance

## Settled owner direction

Use **Explore & Learn** and **Research** as the two main modes. Their discovery
rules, tools and outputs differ; their Library, papers, notes and source links
are shared. Learning works without a research question. Research has a
persistent project with a question, scope, constraints, evidence, hypotheses
and next steps. A directly relevant paper must be discoverable even when it
falls outside the owner's general interests.

| Attribute | Explore & Learn | Research |
|---|---|---|
| Purpose | Stay current, understand concepts, discover connections | Investigate a question, support a decision, propose an experiment |
| Start | Editable interests, declared background, learning goals, available time | Project/question, scope, constraints, explicitly recorded prior knowledge |
| Discovery | Interest match, known freshness, foundations, variety, bounded exploration | Question/terminology, methods, supporting and conflicting evidence |
| Reading | Terms, prerequisites, equations, code walkthrough, reading order | Evidence, comparisons, assumptions, limitations, reproducibility |
| Outputs | Learning notes, paths, connections, optional self-checks | Cited answers, comparison tables, unresolved questions, experiment proposals |
| Success | Owner usefulness, comprehension, manageable effort | Question coverage, retrieval, factual support, uncertainty, next actions |

Both modes support a grounded deep dive when separately qualified and enabled.
A learning dive builds understanding; a research dive examines evidence around
a question. Shared grounding standards do not become weaker in learning mode.

## Initial personal lens

Use the saved owner profile as the authority, without rewriting it from this
plan. The declared priority is agentic systems/research automation; retrieval,
RAG and knowledge organization; evaluation, verification and efficient
inference. Rocket Twin's scientific ML/control watch is adjacent, and spatial
AI/3D creation is lighter exploration. These are editable priorities, not
eligibility conditions for question-driven Research.

The existing organizing question about a useful, source-grounded personalized
research agent remains saved. Offer it as a project starting point through an
explicit action; do not silently turn every saved question into a project or
make it a prerequisite for Explore & Learn.

## Reversible defaults

- New users and unqualified legacy URLs open Explore & Learn. Existing local
  behavior remains available until migration gates pass; no launch redirect
  may discard focus, filter, cursor, view, exact version or passage.
- Research shows an active-project selector and a clear question. With no
  project, offer create/select; Library and manual Reader remain usable.
- One active project in a route; many projects can reference one work. Learning
  threads can be linked to multiple projects without copying the work or note.
- A mode switch changes context deliberately. It does not save a form, submit
  a label, rewrite interests, promote an inference to fact or dispatch a job.
- Declared background/learning goals are optional and editable. Reading a paper
  does not certify mastery; a click does not establish relevance or consent.
- Existing saved state stays shared. Project membership is a separate link;
  removing a source from a project does not delete it or its notes from Library.

## Success criteria

| ID | Demonstration required |
|---|---|
| M1 | Today is useful with interests/time and a blank question; no fabricated summaries |
| M2 | Research retrieves a direct question match outside selected interests, with inspectable reasons |
| M3 | Investigate this creates/links a project through an explicit retry-safe action and preserves exact source/version/passage |
| M4 | Learn prerequisite carries a return link and resumes the same project/evidence position |
| M5 | Notes and reading state survive mode changes, reload, restart, failed saves and version changes without duplication |
| M6 | Desktop/mobile/keyboard navigation, URL/history and draft guards preserve context across both modes |
| M7 | Separate evaluation reports distinguish proposed machine judgments, actual human labels and unscored denominators |
| M8 | Disabled generation cannot build a provider client; private notes/history remain excluded from remote context by default |

## Non-goals and honesty rules

No automatic publishing, arbitrary code/model execution, new subscription,
new provider authorization, inferred personal mastery or claims of full
literature coverage. Metadata, abstracts, retained excerpts and full text keep
their actual version-specific availability. Missing full text remains missing.
Assumptions, observations, hypotheses and proposed experiments have distinct
labels. A mechanical checker pass is not scientific truth or human usefulness.
