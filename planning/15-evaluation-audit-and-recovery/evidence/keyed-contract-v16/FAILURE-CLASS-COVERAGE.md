The focused audit inventories each local rejection as wire-enforced, server-derived or necessarily semantic. JSON Schema cannot establish factual support, priority/relevance, quote correctness, duplicate JSON serialization keys or causality of a later verdict. Those checks remain local and cannot be replaced with prompt instructions. Shared definitions keep named maps compact; remote compilation/actual token fit remain unmeasured.

Recoverable first-draft repair was audited but is not enabled: the journal currently requires draft/check/repair/check and a valid first draft. A safe draft/rejected-diagnostic/repair/check path would need a separately bound journal/progression change; silently treating an invalid draft as a checked response would manufacture evidence. This repair keeps the existing terminal behavior and one completed-quality-failure repair.
