# Lossless coverage, abstention and identity path

1. The transmitted response has one required named coverage object per sealed requested part. Each has one status and an explicit collection of gap reasons; duplicate serialized JSON keys and unknown/missing part keys are refused. Required claim slots derive claim IDs; no second model-authored reverse mapping is accepted.
2. Normalization retains every gap reason. A first-reason compatibility summary supports older internal consumers, but re-encoding rejects a conflicting summary. The full collection remains authoritative and its complete meaning enters the current checker context/digest. Independent prose findings at one location remain separate; no conflicting declaration is merged.
3. Raw complete response text and exact bytes remain in the journal. Normalized workflow and current bound verdict persist separately; only the completed check after the current response is current. Repair or uncertain recheck cannot borrow earlier judgments.
4. Reports retain the normalized coverage rows, full gap collection, declared answer/context roles and explicit full/comparison-abstention disposition. No source note becomes an answered comparison merely because it is cited. Full abstention has no claims or claim references.
5. Reader shows every gap_texts entry, every context-only role and the comparison-unanswered/full-abstention state. Older rows retain their legacy display fallback without acquiring a new schema or acceptance status.
6. Experimental notes retain full coverage JSON when it fits the existing10,000-character note contract. Larger results are saved as an explicit durable exact-job reference; their full persisted result is not truncated into a note. Qualification and simulation downloads export the complete whitelisted result and exact source references, excluding private request/wire/history fields. The backend still retains the raw evidence independently.
7. Exact version/passages remain behind citation controls; missing or drifted material remains unavailable. Saving a reference does not manufacture new material or silently bind to a newer source version.

Real isolated Postgres integration and the complete protected replay test server persistence/current verdict binding. Browser fixtures test render, save request body, download, keyboard and passage-link behavior but mock the API; they are not a separate proof of server persistence or scientific support. Human labels remain blank.
